# MY ROOM — Your own pace

방바닥을 홈 화면으로 사용하는 SVG 팝아트 공간입니다. 음악·영화·신문 포스터를
선택하면 해당 활동의 물건들이 펼쳐지고, ‘방으로’를 누르면 다시 포스터로 정리됩니다.
홈 위젯은 Material 3 Expressive의 대비되는 형태, 큰 주요 동작, 반응하는 모서리와
연속적인 움직임을 참고했습니다. 음악 공간의 기존 사선 구도와 여섯 LP는 유지합니다.

## 실행

Node.js 20.19+ 또는 22.12+에서 실행합니다.

```sh
npm install
npm run dev
```

`npm run build`는 `dist/`를 만들고, `npm run preview`는 빌드 결과를 엽니다.
`npm test`는 공유 투영, 높이·그림자, 활동 전환 중 재조작, LP 착지, reduced motion,
여섯 곡의 SVG 출력과 포인터 좌표를 검사합니다.

## 홈에서 활동으로

| 포스터 | 현재 연결된 동작 |
| --- | --- |
| 음악감상 | 턴테이블과 LP가 바닥에 펼쳐집니다. 선택·도킹·재생 장면·일시정지·복귀를 지원합니다. 실제 음원은 미연결입니다. |
| 영화감상 | 프로젝터와 벽면 스크린이 나타납니다. 직접 만든 SVG 모션 스터디를 재생하거나 기기의 영상 파일을 열 수 있습니다. |
| 신문 보기 | 신문과 커피가 펼쳐집니다. 직접 작성한 샘플 기사 세 편을 읽기 창에서 열 수 있습니다. 실시간 뉴스 피드는 연결하지 않았습니다. |

영상 파일은 Object URL로 브라우저에서만 재생하며 업로드하지 않습니다. 다른 파일을
열거나 페이지를 떠나면 URL을 해제하고, 홈으로 돌아가면 재생을 멈춥니다.
활동 전환은 현재 위치와 속도에서 이어지므로 돌아가는 도중 다시 선택할 수 있습니다.
숨은 활동은 포커스와 입력을 받지 않으며 홈으로 복귀하면 포스터로 초점을 돌립니다.

## 조작

- 하단 ‘방으로’ 또는 `Esc`: 홈으로 복귀. 기사 읽기 창에서는 `Esc`로 기사만 닫습니다.
- 음악 공간의 구도 버튼 또는 `1`–`4`: 사선 / 넓게 / 반대편 / 벽 쪽.
- 음악 재생 버튼: 도킹 → 톤암 → 회전·벽면 장면. 다시 누르면 일시정지합니다.
- 음악 공간에서 `S`: 정지, 방향키: 이전·다음 LP, 배경에 초점이 있으면 Space: 재생.
- 배경 드래그: 바닥 전체의 기울기 조절. 휠 또는 `−` / `+`: 그림 크기 조절.
- 빛 슬라이더: 07:00–19:00 사이 창문 빛, 제목 그림자와 물체 그림자의 변화 확인.
- ‘흐름’: 장면 속 시간을 약 1분에 한 시간씩 왕복 진행. 실제 시계와는 별개입니다.

움직임 줄이기 설정에서는 착지와 구도 전환이 즉시 끝나고 자동 시간 흐름, LP 회전과
필름의 CSS 애니메이션을 생략합니다. 직접 선택한 영상의 재생 조작은 그대로 사용할 수 있습니다.

## 디자인과 코드

| 파일 | 역할 |
| --- | --- |
| `src/floor-home.js` | 홈 포스터, 시네마·신문 데모, 읽기 창, 활동 입력과 포커스 |
| `src/activity-motion.js` | 활동별 표시량, 중단 가능한 전환, 순차 착지, 포스터의 바닥 위치 |
| `src/floor-scene.js` | 공통 바닥·벽 투영, 높이를 가진 평면, 빛과 그림자, 구도 정의 |
| `src/vector-room.js` | 턴테이블 몸통·상판·톤암, LP 단면과 회전, SVG 경로 갱신 |
| `src/vector-math.js` | 투영 계산과 현재 속도를 유지하는 감쇠 스프링 |
| `src/turntable.js` | 턴테이블의 원본 SVG 도안 |
| `src/record-art.js`, `src/label-art.js` | LP와 레이블 도안 |
| `src/svg-context.js`, `src/tracks/*.js` | 곡별 SVG 인터랙션과 팔레트 |
| `script.js` | 음악 재생 상태, 활동 전환 시 취소, 색상 전환과 프레임 루프 |

바닥 좌표는 `u`, `v`이고 뒤쪽 경계는 `v=0`입니다. 벽의 `z=0`과 바닥의 `v=0`은
정확히 같은 점으로 투영됩니다. `raisedFloor(frame, height)`는 같은 바닥 좌표를
벽과 동일한 수직 방향으로 올립니다. 상판·몸통·판·톤암의 높이를 나누고 그 사이에
SVG 옆면을 연결해 두께를 만듭니다. `shadowFloor`는 광원 반대쪽 바닥에 그림자를 남깁니다.
구도와 화면 비율이 바뀌어도 바닥, 물체의 접점, 높이, 그림자가 함께 움직입니다.

LP는 원본 SVG를 유지하고 네 모서리를 CSS `matrix3d`로 투영합니다. 이 행렬은
벡터를 화면에 맞추는 용도이며 WebGL이나 3D 렌더러를 사용하지 않습니다.
포스터는 바닥에 붙인 얇은 종이, 턴테이블과 LP는 그 위에 놓인 두께 있는 물건으로 구분합니다.
