# ROOM: 창과 위젯으로 구성하는 개인 전시

2026-09-08. 최신 피드백과 사용자가 첨부한 이전 화면을 반영해 창·앱·위젯 형태와 흰색 전시 타이포그래피를 복원했다.

## 시각 구성

- 큰 이미지 창 `afterimage.png`, LP와 파형이 있는 `sound.exe`.
- 메모 `untitled.txt`, 날씨 포스터 `chromatic.study`, 중첩된 방 링크 `elsewhere.room`, 영상 플레이어 `moving_image.mp4`.
- 실물 사물의 외곽과 러그를 제거하고 크기가 다른 창들을 겹친다. 코발트 배경, 큰 ROOM 활자, 평면 인쇄 조각은 유지한다.
- 왼쪽 아래 방 제목과 한국어 설명, 전시 번호, 현지 시각, 작은 흰색 문구를 복원한다. 방 이동·코드 실행에 따라 제목과 전시 번호가 갱신된다.
- 검은 상·하단 띠를 유지하고, 편집 창도 검은 톤으로 통일한다. 편집 시에는 장면 제목을 줄이고, 모바일에서는 작은 장식 문구 일부를 생략해 공간을 확보한다.

## 깊이와 조작

오브제 본체는 네 꼭짓점의 평면이다. 컬러 이미지와 높이 지도를 같은 좌표로 그려 POM을 적용한다. 셰이더는 32–64단계로 높이 지도를 탐색하고 교차점을 보간한다. 창의 테두리·큰 활자·이미지 안쪽의 층에 깊이를 준다.

`relief` 범위 0–0.65, 오른쪽 드래그로 조절하는 제한된 시점, 드래그·회전·크기 변경을 유지한다. 클릭 판정도 높이 탐색 뒤의 알파를 확인해 투명한 테두리 뒤의 창을 선택할 수 있다. 실제 콘텐츠는 각 창을 클릭하면 열린다.

기존 파일 종류 ID와 저장된 배치·초안·콘텐츠를 그대로 읽으며 자동 초기화하지 않는다. 기본 템플릿과 사진 모음의 예시는 새 창 디자인을 사용한다.

## 작품 위에 펼치는 편집 도구

고정 사이드바를 제거하고 캔버스가 편집 모드에서도 화면 전체를 채우게 했다. 보관함·코드·속성은 검은 프레임과 부드러운 그림자를 가진 독립 창으로 열리며, 제목 표시줄을 잡아 원하는 위치에 놓는다. 모든 창은 가장자리·모서리의 8방향 크기 조절과 최대화를 지원한다. 반대편 가장자리를 고정하며 마우스를 따라 즉시 반영하고, 크기 변화에 따라 오브제 목록의 열 수도 달라진다. 방 파일은 코드 창 왼쪽에 통합했다. 왼쪽 위 버튼이나 단축키 3으로 접고 펼치며, 접으면 코드 영역이 넓어진다. 접힘 상태는 기기에 저장한다.

코드 영역은 큰 파일명, 여백, 얇은 밑줄 탭과 두 자리 행 번호로 구성한다. 연두색은 선언과 숫자, 보라색은 문자열에 사용한다. IDE 경로 막대와 사각 파일 탭은 제거했다.

오브제 보관함은 14종의 실제 창·위젯 그림만 두 열로 나열하고 세로로 스크롤한다. 카드 테두리·번호·별도 이름과 설명을 제거했으며, 위젯 자체가 클릭·드래그 대상이다. 이름은 툴팁과 접근성 레이블로 제공한다. 하단의 작은 검은 도구 모음에서 창을 열고 닫으며 실행 취소·다시 실행·격자·스냅을 사용한다. 모바일에서는 도구가 한 장씩 열리고 작품은 그 뒤에 남는다.

선택 테두리는 실제 오브제의 각도를 따라간다. 원형 손잡이로 회전하고 사각 손잡이로 크기를 바꾸며, 이동·회전·크기·디자인·속성·복제·삭제는 글자를 없앤 아이콘으로 선택 가까이에 나타난다. 툴팁과 접근성 레이블은 유지한다. 손잡이에는 방향키 조작을 제공한다. 조작 중에는 카메라를 고정하고, Escape로 되돌릴 수 있다.

도구 창 배치는 방 문서와 별도 저장한다. 코드 창을 닫아도 초안은 유지하며, 실행 오류 시 마지막 정상 작품을 보존한다.

## 위젯 확장

기존 여섯 종류에 디지털 시계·달력·계산기·터미널·카세트·라디오·오실로스코프·픽셀 스케치를 추가했다. 각 위젯은 서로 다른 비율과 그래픽을 사용하며 기존 평면 POM과 투명 외곽 클릭 판정을 공유한다.

시계·달력은 현지 시각을 표시하고, 계산기와 달력은 열어서 조작한다. 픽셀 그림은 방 파일의 `content`에 저장해 배치된 작품에도 반영한다. 기존 저장된 방에는 새 위젯을 자동 추가하지 않는다.

## 형태와 디자인 선택

14종에 32개 디자인을 제공한다. 원형 이미지·레코드·아날로그 시계·디지털 캡슐·구름·햇살·테이프 릴·아치·팔레트 등 사각 프레임을 벗어나는 실루엣을 추가했다. 색상 지도와 높이 지도에 같은 외곽을 그려 기존 POM과 투명 클릭 판정에 연결한다.

보관함에서 종류를 누르면 그 위젯의 디자인들을 고른다. 날짜는 원형 날짜판·티켓·찢어진 페이퍼·월간 달력 네 가지다. 뒤로 가면 전체 목록의 스크롤 위치를 복원한다. 이미 놓인 오브제는 선택 도구의 `◈`로 디자인을 교체한다. `.room`의 `variant`만 수정하므로 위치·회전·크기·콘텐츠와 주석은 유지한다. 실행 취소와 저장도 같은 이력을 사용한다. 이전 파일에서 디자인이 생략되면 `classic`으로 읽는다.

## 마우스 조작과 하단 아이콘

편집 모드의 데스크톱 왼쪽 버튼은 선택·이동에 사용한다. 오브제 위 오른쪽 드래그는 회전하며 크기 도구에서는 크기를 조절한다. 손잡이도 마우스에서는 오른쪽 버튼을 사용하고 터치·방향키는 유지한다. 선택한 오브제 위 스크롤은 POM 깊이를 조절한다. 연속 휠 입력을 하나의 변경으로 묶고 Escape로 취소할 수 있다. 빈 공간에서는 오른쪽 드래그로 시점을 기울이고 스크롤로 확대·축소한다. 감상 모드에는 예전의 포인터 반응을 복원했다. 일반 마우스 이동으로 시점이 조금 기울며, 편집 모드에서는 자동 반응을 끄고 오른쪽 드래그·스크롤을 유지한다.

하단 바는 헤더의 검정·연노랑을 공유한다. 장식 별, 텍스트, 단축키 숫자를 없애고 동일한 선 굵기의 SVG 여섯 개로 정리했다. 오브제 보관함·코드·실행 취소·다시 실행·스냅·격자만 남기며 활성·비활성·키보드 초점 상태를 구분한다.

## 창의 형태와 크기

오브제·코드 창에서 녹색 기운과 반복 선 장식을 덜고, 중립적인 검정·회색과 연노랑 포인트를 사용한다. 헤더는 같은 SVG 제어 아이콘, 얇은 구분선과 12px 모서리를 공유한다. 코드 파일명은 본문에 한 번 크게 표시하고 왼쪽 방 파일은 얇은 활성 표시로 구분한다. 이미지 미리보기는 비율을 미리 확보해 로딩 중 목록 높이가 흔들리지 않게 한다.

데스크톱에서는 8방향 크기 조절, 제목 드래그, 더블 클릭 최대화·복원을 지원한다. Escape로 진행 중 조절을 취소하며 키보드로도 같은 경계를 조절한다. 모바일에서는 상단을 끌어 하단 위치를 유지한 채 높이를 바꾼다. 모바일 높이와 데스크톱 배치는 별도로 기기에 저장한다.
